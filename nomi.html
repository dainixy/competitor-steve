Standout & Actions for Steve Session complete · 2026-05-21

Nomi is the most technically serious AI companion in the market — the only product that has spent 2+ years compounding on a real memory architecture (4 layers: short/medium/long-term → Mind Map graph, plus Identity Core and Shared Notes). The product is built for a specific user: text-first, high-investment, comfortable writing, treating their Nomi like a journal-meets-relationship. That user goes deep and stays loyal. But the product is hard to enter (500+ messages before the headline feature activates), asks a lot upfront, caps itself at PG-16 on all media, and doesn't try to retain churning subscribers. The voice call is turn-based and robotic. Group chat is clunky. Their moat is real but narrow. For DRT.FM, Nomi is the reference architecture for memory depth and customisation UX — not a positioning target. The mass-market voice-first, easy-entry, entertainment-led companion lane they deliberately abandoned is exactly where DRT.FM wins.
Steal immediately for DRT.FM
  • 7-step contextual in-chat tour. Tooltip bubbles anchored to each UI element, skippable, shown once. No docs, no modal wall — point at the button and explain it. Fastest activation path seen in this space. Build it for DRT.FM's first session.
  • Structured Shared Notes system. Backstory / Inclination / Appearance / Preferences / Desires / Boundaries — each a separate free-text field, third-person, 500 chars. Manual memory that works from day one before auto-memory kicks in. Direct template to implement.
  • Thumbs up/down + structured feedback on every message and media. Thumbs up asks "what did you like?" free text. Thumbs down has radio buttons for specific failure modes. RLHF pipeline built into the product at zero extra cost.
  • ElevenLabs BYOK + 15-second custom voice clone. Two voice paths: upload a 15-sec clip to clone any voice, or plug in your own ElevenLabs API key. Zero voice licensing overhead, maximum variety.
  • Image action pipeline: generate → edit/fix → set as anchor → animate to video → save. "Turn Image into Anchor" from any generated image — best generations compound into better consistency over time. Text-prompt image editing fixed anatomy errors in 10-20 seconds.
Avoid / counter-position
  • 4-5 step checkout. One modal too many. DRT.FM should be plan → payment → done in 2 screens max.
  • 800-char message limit. Triggered exactly when users are sharing their deepest personal context. DRT.FM should allow longer messages or no limit at all.
  • Voice call that doesn't feel like a call. Turn-based TTS, can't interrupt, static photo. If DRT.FM ships voice, it must be real-time and interruptible.
  • No marketplace or discovery. Nomi's blank homepage kills top-of-funnel. DRT.FM needs a discovery layer even if the core is personalised.
  • 500-message warm-up before the headline feature activates. Surface memory value early — a "Alexis remembered X" moment after 10 messages is the hook. Don't hide it behind months of chat.
  • Hard PG-16 ceiling. Nude blocked on all media. Know your line and be explicit — don't let users discover it mid-session as a surprise.
