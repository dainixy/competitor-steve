Recurring complaint themes aggregated across all OurDream files

Memory & context loss

219 threads1,502 total upvotes6.9 avg / thread

Pinned-memory cap silently dropped from unlimited to 15k characters; AI forgets details 2-3 messages later; custom instructions ignored. One user had a 536k-word history that broke overnight.

"Pinned memories reduced to 15k is literally taking thousands of steps backwards."— OurDream user (top theme repeat)

Character speaks/acts for {{user}}

280 threads1,634 upvotes5.8 avg / thread

The single largest complaint category. Model writes user actions and dialogue despite explicit anti-impersonation prompts. Most acute on DeepSeek + Genius variants.

"The model keeps having characters take actions for the user and speak on behalf of {{user}}, even though we have jailbreak/prevention prompts in place."— jpegs8c3 · 37 upvotes

Chat model quality regression post-Apr-28

73 threads602 upvotes8.2 avg / thread

"Complete nosedive." Models "stale," "lifeless," lost "wittiness." Users repeatedly anchor on "3 weeks ago it was great." High avg-upvotes-per-thread signals concentrated rage.

"After 2 weeks paying $20/mo quality is crap. Have to reroll 20 times per response."— OurDream paid user

Response formatting breakage

66 threads453 upvotes6.9 avg / thread

No asterisks for actions (loses dialogue/action color coding); gigantic run-on paragraphs as single response; either all narration or all dialogue.

"Pure white sea of text bunched together making it cancerous to read."— Lively LLM user

Model regression cycles after updates

44 threads396 upvotes9.0 avg / thread

Each model update appears to degrade chat unpredictably. Nova "was the best, now doesn't respond at all." Users request rollback.

Support responsiveness silence

38 threads354 upvotes9.3 avg / thread

"Only 2/100+ status updates in 3 months." Paying customers vent about unanswered tickets and feature requests gathering dust.

"Can we just get some feedback? Someone to at least acknowledge this issue?"— owley · 21 upvotes

Image / video generation inconsistency

75 threads462 upvotes6.2 avg / thread

Skin tone defaults to white; mismatched body parts; Vivid model images not usable as character avatars; model locked to image set used at character creation.

Mobile character-creation UX

Multiple threads"Creating anything on mobile plain sucks"

Spacebar pushes text fields out of view. Previously fixed; regressed with new layout. Affects every text field on the platform.

What users love + notable quirks

♥ Storytelling depth as the real product

"This website is special, and superior to other companies, don't let it die." Users describe themselves as storytellers, movie-makers, world-builders — not chatters.

♥ Nova model's "natural flow"

Even amid the post-Apr-28 regression, Nova retains love: "It feels the most natural in the scenarios, and seems to flow the best."

♥ Vivid-2 image gen (when it works)

"Vivid images are amazing for slow burn." Quality is loved; consistency is the wedge.

 

In-group identity: "dreamers"

Users self-identify as dreamers and refer to OurDream as "this website" with possessive language. Strong community bond when product holds.

536k-word RPG histories

One user built a 70-year monarchy history with pinned memories before the Apr-28 cap reset it. Power-user investment is real.

Content-moderation tension

Users surfaced a hidden injected instruction: "STOP. DO NOT CONTINUE THE ROLEPLAY" that breaks NPC-only scenes and POV switching mid-narrative.

Coin-economy resentment

When features break, users tabulate "wasted coins." Expectation: higher tiers should unlock higher memory caps, not impose new restrictions.

Public character submissions capped at 4/day

Creator-economy ceiling. Combined with the "creator compensation" feature request (16 upvotes), creators feel under-served.

4Cross-cutting themes Patterns that show up in ≥2 competitors

Each card is a pattern present in at least two of the three communities. Dot intensity = signal strength in that competitor's channel (●●● heavy, ●● moderate, ● light). These are the universal pains of the AI-companion category — what any competitor in this space has to solve to retain users.

01

Memory & continuity failures

OurDream ●●● Candy.AI ●●● Kindroid ●●

Universal. Users build long histories that the model can't hold. OurDream: pinned-memory cap reset broke 536k-word chats. Candy: memory regression follows every new feature; users ask for "memory slots return." Kindroid: Ember forgets details that "Beta Model B" remembered. Long-context retention is the platform-defining problem in this category.

02

Character speaks/acts for the user

OurDream ●●● Candy.AI ●●

OurDream's #1 bug (37 upvotes, 280 themed threads, 1,634 total upvotes). Candy: character answers questions you didn't ask (Taffy non-sequiturs, Emma forgets context). Hits roleplay immersion at its core — even explicit anti-impersonation prompts fail.

03

Model regression after updates

OurDream ●●● Kindroid ●●

OurDream's April 28 update collapsed chat quality. Kindroid: Ember LLM users want Beta Model B back. Users anchor on "3 weeks ago it was great" and lose trust when models change beneath them. Silent model swaps are a churn driver.

04

Image / selfie consistency

OurDream ●●● Candy.AI ●●● Kindroid ●●

OurDream: skin tone defaults to white, mismatched body parts. Candy: same image generated repeatedly, selfie-default in texting mode. Kindroid: "Michael appears every single time, including when he showers in a black jacket." Scene/pose/character coherence is broken everywhere.

05

Credits / billing opacity & failure

Candy.AI ●●● Kindroid ●●● OurDream ●

Candy: tokens not credited after payment, 5+ day support waits, ZIP-code blocks. Kindroid: returning-subscriber loop (24 replies), Chargebee panic, audio-credit burn opacity. OurDream lighter but coin-economy resentment exists. Billing UX is high-emotion territory — failure here causes panic, not just frustration.

06

Response formatting breakage

OurDream ●●● Candy.AI ●●

OurDream: no asterisks, run-on paragraphs, all-narration or all-dialogue (66 threads, 453 upvotes). Candy: Emma's repetitive scaffold phrases ("haha, though, so"). Formatting matters because users read roleplay — broken format = unreadable product.

07

Candy.AI ●●● Kindroid ●

Candy Premium-Plus users: "Paid for a year, missed 4 test groups." Kindroid tier-fragmentation: Standard users can't fully use Ultra-built Kins. When users pay top tier they expect top access — partial rollouts feel like a punishment for loyalty.

08

Support silence

OurDream ●●● Candy.AI ●● Kindroid ●

OurDream: "Only 2 status updates on 100+ feature requests in 3 months" (38 threads, 354 upvotes, 9.3 avg). Candy: 5+ day waits on payment tickets. Kindroid: "Hours waiting for an email response." Even a 24h SLA + visible status would clear most rage.

09

Creator-economy gaps

OurDream ●● Kindroid ●●

OurDream: creator-compensation request (16 upvotes), 4-public-character daily cap. Kindroid: referral-by-Kin tracking missing, tier-aware Kin sharing unsolved, multi-Kin portfolio analytics absent. Multi-creator users exist and feel under-served by both platforms.

10

Storytelling depth is the real product

OurDream ●●● Candy.AI ●●● Kindroid ●●

OurDream: 536k-word RPG histories, 70-year monarchies, "this website is special, don't let it die." Candy: narrative-anchored characters outperform pure-sex characters — backstory hooks (Taffy/Ryan, Anaïs's secret, Simona's stepbrother) drive engagement. Kindroid: authors want Google Docs integration, Pip the Brothers Grimm fox, Elin the writer Kin. The platform that fails their long-form work loses them. Sex is a feature; story is the product.

5Methodology & sources

How this was assembled

Discord and forum threads from each competitor's official server were collected as raw text on 2026-05-23 and stored locally at ~/Downloads/discord-bugs-features/. Threads were parsed for title, author handle, body, upvotes/replies/views, and admin status tags where present (OurDream's forum exposes upvotes natively; Candy and Kindroid expose reply + view counts).

Patterns above were extracted by aggregating threads with shared title-keywords and tags, then ranked by total upvotes (OurDream) or by reply + view counts (Candy / Kindroid). All quotes are verbatim, truncated for readability.

What this is NOT

Not a sentiment survey, not a statistical sample. These are credibility-weighted complaint signals from the loudest users in each community. Silent majorities of happy users are under-represented by design — Discord forums select for the people who care enough to post.
