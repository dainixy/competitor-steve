Competitor Recon — AI Reverse Engineering Stack

Research v2 — May 12, 2026. Question: what AI-native tools beat the "Loom + Gemini" baseline for copying and reverse-engineering competitors?

MENTAL MODEL SHIFT

Stop documenting. Start cloning.

Loom + Gemini gives you a description of what you saw — words about a button, a screenshot of a UI, an opinion about voice quality. That's still manual work translated through a model.

The new 2026 stack pulls the actual artifacts: their React code, their API endpoints with full request/response schemas, sometimes their literal system prompts. Steve doesn't need your notes about how their chat works — he needs their /api/chat/stream request body. We can get him exactly that.

Three layers, three new tools:

  • Frontend code → Magic Patterns Chrome extension / v0 / source-map extraction (no more screenshots — get the actual JSX)
  • Backend API → mitmproxy + mitmproxy2swagger + mitmproxy MCP server (auto-generates OpenAPI spec from observed traffic)
  • AI behavior → mitmproxy intercepts their LLM calls in flight, exposing system prompts, model choice, params (this is how Zed's coding assistant got reverse-engineered last year)

Loom + Gemini stays in the stack but drops to tier 3 — only for qualitative judgment ("does the voice feel emotional?"). The actual engineering deliverable comes from the other two.

Your baseline: Loom screen-record + Gemini 3 Pro video analysis = hands-off UX capture. Good for qualitative impressions, bad for engineering specs. Everything below is what to add ON TOP.
LAYER 1 — THE KILLER UNLOCK

mitmproxy + mitmproxy2swagger + mitmproxy MCP

You put mitmproxy between your browser and the competitor's backend. As you use the site, it captures every single API call — full request bodies, response bodies, headers, auth flow, timing. Then:

  • mitmproxy2swagger auto-converts the traffic to an OpenAPI 3.0 spec. Steve opens that spec and sees their entire backend surface area without writing a line of code. Open source, free.
  • mitmproxy MCP server (new, late 2025) connects mitmproxy directly to Claude Code or any MCP client. You ask Claude in natural language: "find all the endpoints that handle image generation, group them by feature, and summarise the request schemas." It reads the captured traffic and answers.
  • System prompt extraction: when the competitor's frontend calls an LLM (OpenAI, Anthropic, etc.), mitmproxy intercepts the call before it reaches the provider. You see the exact system prompt, model name, temperature, tools. Someone reverse-engineered Zed's coding assistant this way — extracted the full prompt strategy.

What this gives Steve: an OpenAPI spec he can implement against, plus the competitor's literal LLM prompts. That's a 90%-built feature spec without screenshots.

Cost: $0 (all open source, runs locally). Setup: ~30 min one-time. Steve can wire it up.

Gotcha: sites with cert pinning (some mobile apps, rare on web) block mitmproxy. For web targets, install mitmproxy's CA cert in your browser profile and it's transparent.

LAYER 2 — INSTANT UI CLONE

Magic Patterns Chrome extension + v0 + UXMagic Clone-a-Website

Three competing tools, same idea: point at any UI on the web, get production-ready React/Tailwind code out the other end. As of 2026 this actually works for non-trivial layouts.

  • Magic Patterns Chrome extension — capture any UI from any website, get editable components with clean code. This is closest to "AI is paying attention while you browse." magicpatterns.com
  • v0 by Vercel — upload screenshot or paste URL, get pixel-perfect responsive code. Best for full-page generation. v0.dev
  • UXMagic.ai — has a literal "Clone a Website to UI" feature: paste URL, get Figma-ready design + React code. uxmagic.ai
  • Builder.io Visual Copilot — better if you want output to match an existing design system (yours).

What this gives Steve: instead of him implementing "a chat layout that looks like Candy's", he gets Candy's actual layout as a starting component. Tweak, brand, ship.

Cost: v0 free tier covers maybe 5-10 captures/day, Pro ~$20/mo. Magic Patterns has a free tier. Pick one — they overlap heavily.

Bonus — source map extraction: if the competitor ships source maps (most do, even by accident), unwebpack-sourcemap recovers their actual React tree. Pair with Humanify (LLM-driven unminifier) for clean code. This gives you not just the visible UI but every component they ship, including ones behind feature flags. rarecoil/unwebpack-sourcemap · LLM unminification writeup

LAYER 3 — DELEGATE THE BROWSING ITSELF

Stagehand + Browserbase Director (or Claude Computer Use)

This is the "AI takes over my browser" idea, done properly in 2026. Two viable options:

Option A: Browserbase Director (no-code, recommended for you)

  • You demonstrate the recon flow once by browsing naturally. Director watches and converts your session into a Stagehand script — natural-language instructions like "click submit", "extract the pricing table".
  • You can then re-run that script anytime against the same competitor (catch updates), or fork it to run against the other 4 competitors with small tweaks.
  • The script outputs structured data: every screen, every API call, every text snippet. Pipe directly to a markdown doc or your analysis HTML.
  • Browserbase Director · Stagehand SDK

Option B: Claude Computer Use (code, more control)

  • Anthropic's Computer Use loop: Claude takes a screenshot, decides what to click, clicks it, screenshots again. As of 2026 it has a Zoom Action for inspecting small UI elements.
  • You write a prompt like "open candy.ai, sign in with these cookies, go through every feature, output a JSON file with screenshots and notes for each." It runs unattended.
  • Best when you want repeatability + full programmatic control.
  • Computer Use docs

What this gives you: a recon "robot" you can re-run any time a competitor ships a feature. Combined with Layer 1 (mitmproxy), you get a complete delta report: "OurDream added 3 new API endpoints since last week, and here's a screenshot of every new screen."

Cost: Browserbase Director ~$39-99/mo. Claude Computer Use ~$0.10-0.50 per session run. ~$30-100/mo

The new stack, end-to-end

PASS 1 — PASSIVE CAPTURE (one session per competitor)
  • Start mitmproxy. Configure your browser to route through it. (One-time setup; Steve can script this.)
  • Browse the competitor naturally — you're not collecting anything by hand. Just use the product.
  • In parallel: Loom recording running for qualitative voiceover ("voice latency feels like 2 seconds, the image quality is gorgeous").
  • Output: one .har-style mitmproxy capture + one Loom recording per site.
PASS 2 — AI EXTRACTION (fully automated)
  • API spec: run mitmproxy2swagger on the capture → OpenAPI spec file. Done.
  • LLM behavior: grep the capture for OpenAI/Anthropic/etc. endpoints. Pipe to Claude with "summarize the system prompts and model choices used." Done.
  • UX clone: for each screen you want to copy, paste URL into v0 or Magic Patterns → React code. Done.
  • Qualitative notes: upload Loom to Gemini 3 Pro → structured table of impressions. Done.
  • Bundle dive (optional): if their source maps are exposed, run unwebpack-sourcemap → get their full codebase tree. This is the cheat code.
PASS 3 — DELTA AUTOMATION (set and forget)
  • Build a Stagehand script with Director that re-runs Pass 1 on a schedule (weekly?). It generates a diff: new endpoints, new screens, new prompts.
  • Now you're not just doing one-off recon — you have a competitor radar that runs itself.

What I'd skip

  • Scribe / Tango / Guidde — these document what you click. The new stack documents what their system does, which is more valuable.
  • rrweb / OpenReplay — built for recording your own users' sessions, not for competitor recon. Wrong tool.
  • Generic screenshot tools — every screenshot you take by hand is a failure of automation. The only manual capture should be qualitative voice notes on Loom.
