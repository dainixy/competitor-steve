THE STACK

4 Layers, ranked by impact

Each layer is independent. You can adopt them one at a time, starting with the gold.
🥇 LAYER 1 · HIGHEST IMPACT

Clone their frontend (get the actual code)

WINNER Open-Lovable

Paste any competitor URL. It scrapes the entire site and rebuilds it as clean, editable Next.js/Tailwind code you can run locally. This isn't a screenshot — it's their layout as a living component.

Free tier · ~$20/mo Pro Runs local — no vendor sees target

Why it wins: Steve doesn't get "make a chat layout like Candy's." Steve gets Candy's actual layout as a starter file.

RUNNERS-UP
  • v0 by Vercel — screenshot in, pixel-perfect responsive code out. Free tier covers 5-10/day
  • Magic Patterns Chrome ext — point at any element on any site, get React code
  • Cheat code: if they leak source maps (most do), unwebpack-sourcemap recovers their full component tree, including hidden features behind paywalls
🥈 LAYER 2 · THE BACKEND X-RAY

X-ray their backend (get the API spec)

WINNER mitmproxy + mitmproxy2swagger

Put mitmproxy between your browser and the competitor's servers. Browse normally. It captures every API call — request bodies, response shapes, headers, auth, timing. Then mitmproxy2swagger converts that traffic into a clean OpenAPI 3.0 spec.

$0 · open source · runs local Setup ~30 min one-time
  • What Steve gets: a spec file with every endpoint — /api/chat/stream, /api/image/generate — exact JSON schemas, auth tokens, model params
  • Killer unlock: when their backend calls OpenAI/Anthropic, mitmproxy intercepts it. You see their system prompts, model choice, temperature — their literal AI strategy in plain text
  • New 2026: mitmproxy MCP server plugs into Claude Code. Ask in English: "find all image generation endpoints, summarize the request schemas"
🥉 LAYER 3 · THE ROBOT INSPECTOR

Delegate the browsing itself

WINNER Browser Use + Ollama (local LLM)

Write a plain-English mission: "Go to OurDream.AI, sign up, click every menu item, screenshot each screen, log the URL path, export a JSON report." The AI drives the browser autonomously, decides what to click, and loops until done.

$0 with local Ollama · $0.02-0.30/task with API Fully self-hosted · no content policy
  • Run 5 headless browsers overnight — one per competitor
  • 89.1% success rate on real-world web tasks (top open-source agent in 2026)
RUNNERS-UP
  • Stagehand + Browserbase Director — browse once, Director makes a replayable script. Re-run weekly for updates. $39-99/mo
  • Skyvern (local) — no-code visual agents that export flow diagrams. Good if Steve wants zero coding
🏅 LAYER 4 · THE JUDGE

Qualitative ratings (rate the screenshots)

WINNER Qwen2-VL or LLaVA via Ollama (local)

Feed the robot's screenshot batch into a local vision model. Prompt: "Rate voice realism 1-10, image quality 1-10, estimate latency in seconds. Output a structured table." It analyzes the UI frames and returns scored data.

$0 · runs on local GPU/CPU No cloud content filters

Backup: if local isn't sharp enough, use the Gemini 2.5 Pro API directly (not the consumer app). Budget ~$10-30 for 5 hours of footage.

AVOID

What NOT to use

These either upload to cloud, refuse adult content, or solve the wrong problem.

The skip list

Tools that look right but fail on this job.
Scribe / Tango / Guidde
Cloud-only. Uploads every screenshot to their servers. Adult content violates TOS. Your credentials stored on their cloud.
OpenAI Operator
$200/mo. Cloud-hosted. Refuses to interact with adult/NSFW sites. Your session data visible to OpenAI.
Claude Computer Use (API)
Anthropic safety filters flag adult content. High risk of account scrutiny.
Loom + Gemini as primary
Good only for qualitative voiceover. Uploads video to Atlassian's cloud. Gives you words about a button, not the code or API.
FullStory / Hotjar
Records YOUR site's users. Cannot deploy on someone else's site. Wrong tool entirely.
Perplexity Comet / ChatGPT Atlas
Consumer AI browsers. Cloud inference. Will refuse adult content. No structured extraction.
