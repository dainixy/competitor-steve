The 80/20 thesis

Three independent agents agreed on the same maximalist hybrid stack (Blotato + YouTube Analytics + Apify or Metricool + Bluesky). All three over-engineered the first move.

The cheapest decision-quality data we can get this week is:

$0 marginal ~1 Claude Code session covers all 7 channels at baseline + retention on YouTube

  • Blotato API (already paid for) → views, likes, comments, reach, impressions, shares, saves per post per platform — all 7 channels.
  • YouTube Analytics API (free) → retention curve + traffic source + demographics on YouTube — your highest-cadence channel.

That's it. No Apify, no Metricool, no Meta or TikTok app review. We add those only if Phase 0 fails to answer the question.

The diagnostic dead zone Phase 0 leaves

If the dead channels turn out to be IG or TikTok and Blotato's views-only data doesn't make the cause obvious, we'll be guessing. That's the explicit trade. Acceptable because (a) we'll know within 2 days whether Phase 0 is enough, (b) escalation paths are pre-mapped.

What we build (in Claude Code)

Script 1 — Blotato puller

Path: pipeline/17-pull-blotato-analytics.py

  1. GET https://backend.blotato.com/v2/posts?status=published&since=<launch>&limit=250 — paginate via cursor, collect all post IDs across all 7 platforms.
  2. For each post: GET /v2/posts/{id}/analytics — write to analytics/<scene_id>/blotato-<platform>.json.
  3. Skip posts younger than 48h (metrics not settled).
  4. Re-fetch posts at age 7d and 30d to capture long tail.
  5. Use existing blotato-api-key from .mcp.json.

Script 2 — YouTube Analytics puller

Path: pipeline/17-pull-youtube-analytics.py

  1. Google Cloud project → enable YouTube Data API v3 + YouTube Analytics API.
  2. OAuth 2.0 desktop credentials. You click once to grant. Token cached locally.
  3. Call youtubeAnalytics.reports.query with:
    • Metrics: views, estimatedMinutesWatched, averageViewPercentage, audienceRetentionRatio, subscribersGained, subscribersLost
    • Dimensions: video, day, trafficSourceType, ageGroup, gender
    • Date range: channel launch → today
  4. Match each YT post to its scene_id via the post URL (already in Blotato manifest).
  5. Write to analytics/<scene_id>/youtube-deep.json.

Script 3 — Rollup + analyse

Path: pipeline/18-analyse-analytics.py

  1. Read all analytics/*/ JSONs.
  2. Join with scenes/NNNN/meta.json (script, pillar, hook style — already on disk).
  3. Build flat CSV at analytics/rollup.csv for eyeball QA.
  4. Call Claude Sonnet 4.6 with: the joined dataset + channel-brief.md + the diagnostic prompt below.
  5. Output: analytics/report-YYYY-MM-DD.html — auto-open.

Diagnostic prompt (Sonnet input)

You are diagnosing the performance of the Scarred Truth channel — short
vertical videos featuring "Zane," a tattooed wisdom-from-scars character.
Content brief is attached (channel-brief.md).

Posting cadence: YouTube gets ~3 posts/day, the other 6 platforms (Instagram,
TikTok, Bluesky, Facebook, Threads, Twitter) get 1 post/day — same video,
same caption. Account for this asymmetry when comparing.

Data attached:
- Blotato per-post metrics (views, engagement, reach) for all 7 channels
- YouTube Analytics: retention curves, traffic source, demographics
- Scene metadata: script text, pillar, hook style

Diagnose:
1. Which channels are dead (rank by views/post normalised across cadence).
2. For each dead channel — is it (a) sudden cliff, (b) slow decay, or
   (c) never-took-off? Cite evidence from the data.
3. Where in YouTube videos do viewers drop off most? Map to hook style
   and pillar. Which combos retain past the 10-second mark?
4. Which traffic source dominates on YouTube? If recommendation share is
   declining, flag the date.
5. Top 5 and bottom 5 posts overall — return scene IDs + the actual hook
   text so we can pattern-match.
6. Three testable adjustments to make this week, ordered by expected impact.
7. Honest limitations: what you cannot diagnose from this data, and
   what extra data would resolve it.

Output: an HTML report. Be specific. No motivational filler.

Phase 0 → Phase 1 decision gate

Run Phase 0 once. Read the report. Then decide:
  • Stop here if the diagnosis is actionable. Fix the content/posting issues identified.
  • Add Metricool (~$25–30/mo) if the report flags "need follower/non-follower reach split on IG/TT to confirm hypothesis." Connect accounts in the UI; no engineering needed.
  • Add Apify (~$5–15/mo) if you need cheaper depth on specific platforms or want to scrape competitors for benchmarks. Built in Claude Code.
  • Escalate to native Meta/TikTok APIs only if Phase 0 + Metricool both fall short on a specific question. Multi-week app review, no upside until then.
