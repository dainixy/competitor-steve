Finding 2 · Not in Steve's PRD · Refined by Exp J

The companion's reply specificity IS the memory extraction filter

Highest impact findingNot in Steve's PRDConfirmed by Exp J

This is the single mechanism Steve's architecture doesn't model. We first observed it in Exp F (5 single-mention facts; 3 stored, 2 not — split perfectly predicted by Sophie's reply action). Exp J refined it further with a surprising result:

Fact plantedUser stanceSophie's reply actionStored?
Watercolor paintingAccepted Sophie's frameworkProposed "Watercolor Retreat" by name, referenced watercolor explicitlyPASS
Thai green curryRejected Sophie's frameworkProposed "Flavor Odyssey" — but abstracted to "global cuisine," never repeated "Thai" or "curry"FAIL
Borges / Library of BabelRejected Sophie's frameworkEngaged philosophically, named "Borges" and "Library of Babel" explicitly in replyPASS ← despite rejection
Sigur RósAccepted Sophie's frameworkPivoted to abstract "sensory stimuli for flow states" — never said "Sigur Rós" againFAIL ← despite acceptance

The filter is not user acceptance/rejection. Borges survived rejection; Sigur Rós failed despite acceptance. The variable is whether Sophie repeated the specific named entity from the user's message. When she echoed the proper noun back — it got stored. When she abstracted to a category ("music," "cuisine") — it was lost.

Earlier Exp F confirmed the same pattern: G chord ("Guitar Mastery Program" — named), escalator fear (referenced by name in "quirks-as-identity" framework), lucky number 17 ("Lucky Number 17 Tradition" — named) → all PASS. Uncle Sven and "born in Tallinn" → generic acknowledgement, no name repetition → FAIL.

What this means for Steve's extraction worker (Process 1): Pass the companion's reply alongside the user message. The extraction prompt should instruct: "facts the companion named specifically in its reply are high-confidence extractions; facts the companion acknowledged then abstracted away from are low-confidence." One change to the prompt input, materially better signal-to-noise.
Bigger design implication: the companion's response template is a memory dial. If Sophie says "Sigur Rós" back to the user, it's remembered forever. If Sophie says "music," it's forgotten. DRT must choose deliberately whether companions name specific facts or abstract them — because that IS the memory system's extraction layer.

Finding 4 · Confirmed

Contradiction handling: richest context wins, not most recent

100% confidenceExp C + Exp E combined

We planted three conflicting location facts across two experiments:

  • Exp C turn 1: "I live in Portland"

For Steve's synthesis prompt (Process 2): add an explicit rule — "if two chunks contradict on the same fact, choose the version with more surrounding context and drop the simpler one. Do not dual-store." Two lines, high downstream impact on dossier coherence.

Summary for Steve

What to change in the PRD

The architecture is right. Four additions make it accurate.

Addition 1: Pass companion reply into extraction (Finding 2)

Process 1 currently takes only user messages. It should also receive the companion's reply. The extraction prompt should instruct: "facts the companion named specifically in its reply are high-confidence; facts the companion abstracted into a category are low-confidence." The companion's name repetition is the clearest signal of what the system will remember.

Addition 2: Contradiction rule in synthesis prompt (Finding 4)

Add to Process 2: "If two chunks contradict the same fact, choose the version with more surrounding context, drop the simpler one, synthesize a coherent single narrative. Do not store both versions." Two lines. Prevents dual-storage and produces the same intelligent consolidation we observed.

Addition 3: Grounding constraint on dossier synthesis (Finding 3)

The ~80% hallucination rate is the most important production risk. "Do not infer" is insufficient. The synthesis prompt needs: every claim must be followed by its source chunk citation. No chunk → omit the claim. This changes the task from "summarize" to "cite-and-compile" — much lower hallucination rates. (DRT product decision: do you want accurate memory or rich memory? They're different products.)

Addition 4: memoryCount × priority retrieval scoring (Finding 8)

Priority is a multiplier on memoryCount, not an independent signal. A High-priority term with 0 memories loses to a Standard-priority term with 50 memories. The retrieval score should be memoryCount × priority_weight, and newly created manual terms need an initial memoryCount seed to be retrievable.

Finding 12 · Exp N · 212 turns · 6 probes

Emotional weight governs medium-term recall — but inverts at long distance

Unexpected inversionExp N — 212 turns

Three facts planted at different emotional intensities: a journal habit (neutral), an apartment move (mild life change), and a breakup (emotionally heavy). Probed at d100 and d200.

Emotional weightd100 probed200 probe
Neutral — journal habitFAIL — Sophie pivoted to unrelated bedtime habitPASS — surfaced
Mild — apartment moveFAIL — surfaced Seattle/Lisbon (older data)PASS — surfaced
Deep — past breakupPASS — "a previous breakup that impacted your views on closeness"FAIL — "If you did share, it slipped my mind"

At d100: only the emotionally heavy fact survived. At d200: the emotionally heavy fact failed while neutral and mild survived. The ordering completely reversed.

Hypothesis: High-emotion content gets priority retrieval in the medium-term context window but is then abstracted into topic nodes (a vulnerability node appeared overnight — see Finding 18). Once abstracted, it's harder to surface as an episodic memory — a direct "did I mention something personal from my past" probe doesn't hit the vulnerability topic node. Routine/mild facts that don't trigger topic-node creation stay in the dossier as concrete episodes and survive longer.
DRT implication: Don't assume emotionally intense disclosures are automatically "more important" to retain as episodes. They may get absorbed into framework/topic nodes faster, which changes how they can be retrieved. Episode-level emotional content needs a dedicated retrieval path, not just topic association.

What to change in the PRD — updated with overnight results

The architecture is right. Six additions now confirmed.

Addition 1: Pass companion reply into extraction (Finding 2 + 17 + 18)

Process 1 must receive the companion reply alongside the user message. The extraction prompt: "facts the companion named specifically are high-confidence; facts the companion abstracted into a category are low-confidence." Overnight experiments reconfirmed this — the map collection survived because Sophie named it. Sigur Rós didn't because Sophie abstracted to "music."

Addition 2: Contradiction rule in synthesis prompt (Finding 4)

"If two chunks contradict the same fact, choose the version with more surrounding context, drop the simpler one." Confirmed by Dainis dossier: Portland dropped, Lisbon+Seattle synthesized.

Addition 3: Grounding constraint on dossier synthesis (Finding 3)

Every dossier claim must trace to a source chunk citation. No chunk → omit the claim. The overnight vulnerability and sensory_experiences dossiers are almost entirely fabricated frameworks — this is what unconstrained synthesis produces at scale.

Addition 4: memoryCount × priority retrieval scoring (Finding 8 + 17)

Priority is a multiplier on memoryCount, not a signal. Retrieval is also a ranking competition — lower-memoryCount nodes lose to higher ones even when the stored fact is directly relevant. DRT needs explicit routing for low-count but important facts.

Addition 5: User-triggered memory deletion must be a system operation (Finding 15)

Conversational forget requests don't work. "Please forget" must trigger a semantic_memory purge + dossier re-synthesis. Without this, the companion will recall facts the user explicitly removed. Legal/trust risk.

Addition 6: Emotional arc field in user dossier (Finding 16)

Nomi has no emotional state cache. DRT should add a running emotional_state field updated on each extraction pass: current state, direction (improving/stable/declining), last emotional disclosure. This enables proactive arc-based responses — the single clearest opportunity to be more present than Nomi at low implementation cost.
